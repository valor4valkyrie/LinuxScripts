# Linux Scripts

## Scripts to easily update, clean, reboot or shutdown Debian based Linux based operating systems.

Each script runs an update, upgrade and a clean of Linux/Debian based packages. Each script name
ends with the final process so `Update.sh` just updates the system without a follow up process. While
`UpdateShutdown.sh` ends with the computer shutting itself down. This process also checks for a `Flatpak` installation and updates that, if applicable.
